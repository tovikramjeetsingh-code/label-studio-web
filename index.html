1 · Upload your file

CSV or Excel — one row per SKU-size. Three formats are auto-detected:
① Label Template — brand, article type, style name, style id, size, seller sku code, sku code, mrp, month & year of manufacture
② Myntra STN Summary — the portal export; Seller SKU = Vendor Article No, Month & Year = current month
③ Seller Listings Report — the portal listings export; Month & Year = current month
Extra columns are ignored. Any other file → you'll be asked to match its columns to the label fields.
Only have a list of SKUs? Load a reference below, then upload the list — missing details (brand, MRP, style…) are filled in automatically.
Copies per label: a Quantity/Qty/Copies column sets how many of each label to print; you can also edit Copies per row in the review table. Print all prints that many of each.
Upload the Myntra system-generated barcode PDF(s) — one item barcode per page. You can select/drop several PDFs at once; they're combined into one batch and laid out automatically. Each item code becomes a sticker in your chosen size and code (encoding the item code): 50 × 25 mm shows item code + seller SKU + description; 25 × 15 mm shows the code + item code + seller SKU. Print all sends raw TSPL straight to your TSC printer (50 × 25 prints 2-up, 25 × 15 prints 4-up).
Free-style rack / location labels. Upload a CSV or Excel where the first column is the rack code (encoded + printed big). An optional second column prints as a small caption. Pick 1D barcode or QR (2D) below. Each row becomes a 25 × 15 mm sticker; Print all runs them 4-up on the same TSC roll.
Upload the STN summary CSV(s) first — this tab won't print without one. Every label is built from that dispatch, so nothing outside it can be printed by mistake. Then scan or type any of:
① Item barcode (IB…) — the built-in item map turns it into its SKU
② SKU code (e.g. ANUKHeels97088318)
③ Seller SKU code (e.g. 3221-Beige-36) — a bare VAN covers every size, so include the size
Each match prints its label immediately in the size selected above. Connect the printer under Direct printing first.

Stored SKU reference 📦 built in · no sign-in

The listings catalog and the item-barcode map ship with the app and load by themselves — nothing to enter, nothing to upload. They fill missing fields (brand, MRP, style…) on every upload and power the Find and Scan tabs.

Direct printing 🖨 QZ Tray

Print stickers straight to your label printer — no PDF, no dialog. Needs the free QZ Tray app running on this machine (one-time install; on first print click "Allow" and tick "Remember").
Stop QZ asking every time? Download the trust certificate, put it in C:\Program Files\QZ Tray\ (keep the name override.crt), then right-click the QZ Tray icon → Exit and reopen it. After that QZ never prompts on this PC.
Alignment nudge (mm): X Y +X → right · +Y → down (use if prints land off-centre)
